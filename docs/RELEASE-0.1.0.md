# 木听风音乐 0.1.0

首个公开版本，基于 **NSGo v0.1.0**，同时提供 macOS Apple Silicon、Android arm64 和 Windows x64 下载。

## 功能

- 本地音乐导入、歌曲/专辑/歌手浏览、收藏、歌单与搜索。
- MP3、FLAC、Ogg、WAV、M4A/AAC 播放；安卓格式支持取决于系统解码器。
- 播放队列、随机/循环模式、进度跳转、会话恢复和同步歌词。
- 桌面侧栏、播放条与系统媒体控制；手机底部导航、全屏播放器、歌词及队列。
- Android 后台与熄屏播放、媒体通知及系统媒体控制。
- MyGo Music 兼容的 JS/TS 插件宿主，支持安装音乐源、配置、手动更新和插件提供的登录方式。
- 简体中文/English，深浅外观跟随系统。

## 下载

| 平台 | 文件 |
| --- | --- |
| macOS Apple Silicon | `wood-wind-music-0.1.0-macos-arm64.dmg` |
| Windows 10/11 x64 安装版 | `wood-wind-music-0.1.0-windows-x64-setup.exe` |
| Windows 10/11 x64 便携版 | `wood-wind-music-0.1.0-windows-x64-portable.zip` |
| Android 9+ arm64 | `wood-wind-music-0.1.0-android-arm64.apk` |

每个下载包附带 SHA-256 校验文件。macOS 应用为临时签名，未公证；Windows 未做代码签名。Android 沿用本项目已有签名，通过 GitHub APK 分发。

## 数据与升级

发布包不包含酷狗或其他第三方音乐源插件，不包含个人账号、Cookie、登录凭据、曲库、播放历史或歌单。新安装从本地音乐开始，可自行安装插件并登录。Android 已关闭备份。

覆盖安装保留用户本机数据，不会清除已有插件和登录状态。三平台显示版本均为 0.1.0；内部构建号为 131，Android 可覆盖私用 0.1.30（版本码 130），应用 ID 和签名保持不变。卸载或清除数据会删除应用内的导入副本及其他本机数据，请勿以此作为升级步骤。

## 已知限制

- Windows 为实验性支持：已完成构建与共享逻辑回归，完整真机播放、安装升级、托盘及输出设备切换仍待验收。
- Android 已在荣耀 GT 验证过实际曲库、网络音乐、后台和熄屏播放；真实蓝牙、来电与整夜后台场景尚未完整覆盖。新版框架下的验证范围见[发布验证记录](RELEASE-VALIDATION-0.1.0.md)。
- Android 导入会复制音乐到应用私有存储，额外占用空间；ALAC/M4A 在既有测试设备上未能播放。
- 插件可用性取决于第三方服务和插件实现。暂无跨设备同步、应用自动更新和双击音乐文件关联。

构建源码需要 Go 1.27.3+。完整用法、构建流程与验证边界见 README 和平台文档。
