# 插件与音乐源

木听风音乐现在兼容 MyGo Music 的 `plugin.json` 插件协议。桌面端和安卓端共用同一个纯 Go JavaScript/TypeScript 宿主，各插件独立运行，按需启动，支持异步调用、超时中断、权限、配置与持久化存储。MusicFree、洛雪等应用的插件协议不直接兼容。

## 安装与使用

1. 打开「设置 → 插件 → 安装」。输入 GitHub 的 `owner/repo` 或仓库网址，或选择含 `plugin.json` 的 ZIP 文件。
2. 查看插件名称、版本和网络权限，再确认安装。安装仅载入代码，首次使用才运行插件。
3. 桌面端点击侧栏顶部的音乐源名称切换；手机在「音乐库 → 音乐源」切换，使用插件时也可从顶部下拉按钮切换。
4. 在插件设置中填写服务地址、API key 等配置并点击保存。插件提供登录方法时，可打开登录提示、扫码或使用浏览器回调登录。
5. 从 GitHub 安装的插件可以在设置中检查更新，下载后再次确认安装。移除插件保留其配置和登录数据，重新安装相同 ID 后可继续使用。

也可以把插件目录放进应用数据目录下的 `plugins/<插件 ID>/`，重启应用后发现。开发示例位于 [`examples/demo-plugin`](../examples/demo-plugin)，无需网络，包含歌曲、歌词、歌单、播客、电台和评论。

## 可用功能

插件导出的能力决定导航内容。已接入插件首页与自定义页面、歌曲/歌手/专辑/歌单/播客搜索、搜索分页、歌词与音质、收藏歌曲、歌单编辑、收藏专辑和歌单、关注歌手、播客订阅和节目分页、电台连续播放、评论分页/点赞/发布，以及远程播放源的现有播放控制。

切换音乐源时清除页面缓存，旧请求不会覆盖新音源的搜索结果；正在播放的队列仍通过歌曲自己的音源解析。页面历史和手机三个导航入口都保留音源身份。缺失的插件不会回退到本地音源。

插件的 `requestHeaders` 可以为指定主机的封面和音频附加凭据。封面由宿主读取，安卓带请求头的音频经仅监听回环地址的临时转发服务送入原生播放器，保留 Range 请求，支持拖动进度。转发地址使用随机凭证且不携带上游令牌，切歌或清空播放时关闭。重定向到其他主机时移除鉴权头。

## 平台边界

- 安卓插件应使用纯 JS/TS 和网络接口。依赖桌面可执行程序的插件不能在安卓运行；桌面端则需在插件设置中明确允许其启动程序。
- 当前支持插件自身的扫码及浏览器回调登录。NSGo 尚未提供隔离网页会话和读取 HttpOnly Cookie 的公共接口，因此暂不声明 `host.webSignIn` 能力，让支持能力检测的插件自动退回扫码登录。不能将普通 WebView 中的 `document.cookie` 视为等价实现。
- 安卓仍使用系统解码，格式支持取决于设备；暂停淡出、PCM 频谱和桌面下载缓存不作用于原生播放链路。
- 自动更新检查、插件仓库订阅目录、远程设备选择界面仍未接入；GitHub 单插件安装、手动检查更新与远程播放控制已经可用。
- 插件与实际服务的兼容性取决于插件本身。构建与集成测试不等于第三方服务登录或真机后台播放验收。

## 数据与验证

插件代码保存在应用数据目录的 `plugins/`，配置与存储保存在 `plugin-data/<ID>/`。应用版本来自 NSGo 构建信息，用于插件最低版本检查；开发构建未提供版本时沿用上游的开发模式。

执行 `go test ./...` 和 `go tool nsgo check`。插件测试覆盖真实 JS/TS、权限、存储、安装、更新、解压路径和请求头；界面集成测试覆盖桌面/手机音源切换、插件安装确认、配置保存、卸载保留数据、搜索隔离、播客/电台/评论入口，以及安卓鉴权音频和播放节点稳定性。安卓完整打包使用 `go run ./cmd/android`。
