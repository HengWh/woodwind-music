# 已存音乐使用说明

桌面侧栏的「已存音乐」和手机「音乐库 → 已存音乐」汇总应用保存的插件歌曲。进入该页面无需切换音乐源；原插件移除、账号退出或设备断网后，完整保存的歌曲仍可直接浏览和播放。

## 两种保存方式

| 方式 | 如何产生 | 清理规则 |
| --- | --- | --- |
| 自动缓存 | 在线播放或预取时，音频完整下载并验证后保存 | 超过容量上限时按最近播放时间清理 |
| 保留离线 | 在歌曲菜单、歌单或专辑中选择「保留离线」 | 不受自动缓存上限和清空自动缓存影响 |

已有完整缓存转为保留离线时直接保护原文件，不会再次下载或复制。取消保留后转为自动缓存，之后可能被清理；「移除本地副本」则直接删除对应音频和资料，包含保留离线的副本。

关闭自动缓存只停止新增，不立即删除已有歌曲。设置中的容量上限仅用于自动缓存；保留离线和总占用单独显示。应用卸载、清除应用数据、手动删除文件或磁盘故障仍会使离线内容丢失，离线保存不是备份。

## 浏览和播放

- 按全部、保留离线、自动缓存查看，按歌名、歌手和专辑搜索。
- 按最近保存、最近播放、名称、歌手或占用空间排序；来源、实际音质和资料状态在歌曲信息中查看。
- 按歌曲、专辑、歌手浏览；专辑页只包含本机已经保存的曲目。
- 默认显示播放全部和随机播放；逐首勾选后显示加入队列、保留、取消保留和移除等批量操作，不再提供全选或取消全选。单曲操作也可从歌曲菜单进入。
- 搜索框固定在列表上方，长列表可上下滚动，勾选歌曲后保留当前浏览位置；切换分类、搜索或浏览方式时回到顶部。
- 来自不同插件的相同歌曲 ID 不会混在一起。来源已移除时，仍保留来源名称和本地操作。

从已存音乐发起的播放只读本机内容，不会因全局音质设为无损而重新下载。当前没有无损副本时使用已有版本，实际音质在歌曲信息中显示。需要更高音质可主动选择「以无损音质保留」；升级失败不会损坏旧版本。

移除插件不再清空整个播放队列。完整本地歌曲继续播放；尚未保存的歌曲显示不可用，动态电台补歌和依赖该插件的未完成任务停止。评论、线上收藏和线上歌单写入仍需要原插件。

## 歌词和封面

应用保存歌名、歌手、专辑、时长、音频格式和实际音质，同时保存取得的封面图片、歌词、翻译和逐字时间信息。离线展示读取本机资料，不依赖原图片网址或再次调用歌词接口。

来源没有提供资料，或资料暂时获取失败时，音频仍可保存和播放。歌曲信息显示缺少封面或歌词；来源可用时可选择「补充缺失资料」。补充失败不会覆盖已有有效资料。第一版不把这些信息写回音频内嵌标签。

## 下载任务

「已存音乐 → 下载任务」显示排队、获取资源、下载、完成、等待插件/登录/网络、暂停和失败状态，支持暂停、重试及移除任务。任务中的歌曲尚未完整保存时不计入可播放歌曲数量。

批量保存使用操作当时的歌曲列表，不持续同步线上歌单，也不修改线上收藏。播放、预取和保留同一歌曲、同一目标音质时共用下载。暂停后的重试会重新获取资源；第一版不拼接无法确认版本一致的断点数据。

安卓默认等待 Wi-Fi 或其他非计费网络开始新的离线下载，可在任务中允许当前请求使用移动网络，或在设置中更改默认策略。正常在线播放仍由用户操作发起；移动网络下不会默认形成自动缓存。安卓通过同一个下载文件向系统播放器提供范围读取，拖动进度不会另开一份上游下载。

应用关闭或被系统终止后不保证继续下载，未完成任务在下次启动恢复；用户主动暂停的任务不会自行恢复。磁盘空间不足时任务报告原因，不会删除其他保留离线歌曲来腾空间。只能远程控制播放的插件和不能取得独立音频文件的资源不支持保留离线。

## 数据位置和历史迁移

数据位于应用数据目录的 `media/` 下：`records/` 保存版本化歌曲资料和歌词，`audio/` 保存音频，`artwork/` 保存去重后的封面，`temp/` 保存未完成下载，`tasks.json` 保存任务。记录不保存音频请求的 Cookie、令牌或鉴权头。

旧版 `songs/` 中的缓存会纳入新目录，原音频先继续使用原路径，不要求重新下载。可从既有播放会话匹配的缓存会恢复歌曲身份；不能识别的显示为「未识别的历史缓存」，仍可播放、保留和删除。旧版没有保存的歌词、封面需要在来源可用时补充。

已删除的历史缓存记录有清理日志，避免应用在文件尚被播放器占用时退出，重启后又把它导入。损坏的歌曲记录可根据剩余完整音频恢复为未识别内容；这类恢复内容保守地保留离线，供用户确认后管理。
