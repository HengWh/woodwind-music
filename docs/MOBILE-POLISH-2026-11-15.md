# 移动端体验优化（2026-11-15）

版本 **0.1.30**。本轮覆盖私人 FM、设置、列表、歌词、搜索、队列和歌曲操作，应用标识及签名保持不变。

## 页面与交互

- 私人 FM 使用独立手机布局，取消重复页面标题，收紧封面与字号，收藏、播放和下一首在小屏首屏可达。FM 正在播放时不再重复显示迷你播放条；点击封面可进入完整播放器。
- 设置改为纵向分类目录与二级页面。短选项显示为左侧名称、右侧当前值，开关与说明并排，复杂控件继续使用完整行宽；各分类保留滚动位置。页面返回键和系统返回键先回到设置目录，再退出设置。
- 本地与在线来源均从音乐库右上角进入设置；账户面板保留设置入口。手机隐藏仅适用于桌面播放器的实验效果与 macOS 图标设置。
- 手机歌词正文与译文水平居中，当前句定位在歌词视区中央；首句和末句同样可居中。长句、译文和字体变化参与实际高度计算，尺寸连续变化后会再次校准定位。
- 暂停、收藏等播放状态变化不再重建歌词列表；手动浏览暂缓跟随，点击某句可跳转并恢复跟随。歌词模式减少歌曲信息与控制区留白，改变尺寸或字体时保留歌词模式。
- 队列中的播放状态高亮独立更新，切歌或暂停不打断正在浏览的位置；提供“回到当前播放”，较大的数据刷新也保留列表偏移。
- 搜索接入历史关键词匹配与直接搜索建议，中文输入法组合期间不提交。结果接近底部时自动续页，同时保留手动加载入口；续页过程中保留同一个滚动视图。失败保留已有结果，单独提供续页重试，空页停止自动续页。
- 歌单、专辑、歌手及来源浏览详情加载失败时提供重试和错误详情。歌曲菜单按实际来源能力、歌单归属和固定歌单限制显示操作，避免跨来源添加或修改只读歌单。
- 不可播放歌曲显示明确状态并弱化标题；歌曲信息面板完整显示长标题。当前歌曲高亮同时比较来源和歌曲 ID。

## 列表与封面

0.1.30 进一步修复歌曲行复用：普通歌曲列表、歌单及歌曲搜索结果在回收行时保留按钮与文字视图，内容、无障碍名称和点击动作随当前行索引更新，仅在封面 URL 改变时替换封面子树。避免虚拟列表内部仍反复销毁整行控件。

歌曲和队列继续使用虚拟列表；手机的专辑、歌手等双列网格也改为虚拟列表。搜索追加数据更新列表自身的计数和可见内容，避免全页重建。页面滚动位置回传限制频率，并在滚动结束时保存最终位置。

封面大小占位符根据显示尺寸与设备像素比例请求图片。带认证的封面缓存采用逐条淘汰，达到上限时不再整批清空，减少来回滚动的重复请求。
