## 实测中修复的问题

1. **未实现的网页登录能力阻止了扫码回退。** 哔哩哔哩通过 `typeof host.webSignIn === "function"` 选择网页登录。宿主原先总是声明该方法，即使调用时只能报错。现在 `SetWebSignIn(nil)` 会省略此方法，让插件使用其原有扫码实现；提供真实网页会话处理器时仍保留原功能与权限检查。
2. **桌面播放失败时缺少持续错误提示。** 现在桌面播放条和正在播放页会显示错误/缓冲状态，并保留插件提供的不可播放原因；网易云的 `-460` 错误可以直接在界面看到。

上述修复均补充回归测试。扫码兼容、桌面错误展示及播放器相关测试和 `go tool nsgo check` 已通过。此记录不包含安卓真机、HE-AAC/ffmpeg、登录后账号功能、VIP/地区限制或长时间稳定性验收。
