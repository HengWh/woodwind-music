# 木听风 · 四季图标配色设计稿

保留现有耳机、三层松树、两片风叶与圆角底板，延续赛璐璐插画质感。仅探索四季配色，主题架构与正式图标引用保持原样。

| 季节 | 配色 | 设计方向 |
| --- | --- | --- |
| 春 · 新芽 | 薄荷绿、浅樱粉、奶油白 | 嫩绿树冠与柔和粉绿底板 |
| 夏 · 晴风 | 青碧、晴空蓝、鲜绿 | 青色耳机与更鲜明的树冠 |
| 秋 · 赤叶 | 朱红、炭黑、暖白 | 黑色耳机、红色树冠、白色底板，呼应当前界面 |
| 冬 · 霜音 | 冰蓝、银白、深蓝 | 银白耳机与霜蓝树冠 |

由内置图像生成工具基于当前 resources/icon.png 编辑，随后通过同一工具尝试细化透明边缘。完整配色提示词见 generation-prompts.txt。

每个季节目录包含生成原稿 source-draft.png 与 1024、512、256、128、64、32 像素 PNG 导出。preview-four-seasons.png 展示同一比例与深浅背景下的对照。

当前状态为配色设计稿。透明外缘仍有少量生成残边，正式发布前需要进一步精修；本轮未替换 resources/icon.png、resources/icon.icns，也未更改应用主题或图标生成入口。
