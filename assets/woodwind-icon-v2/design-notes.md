# WoodWind 图标 v2

保留耳机、松树、两片风吹叶子与冰蓝底板的原始构思。使用内置图像生成工具打磨材质、统一光照，并导出标准尺寸与深浅背景预览。

主要变化：深蓝金属耳机、蓝色织物耳垫、更高对比的绿色松树、细致倒角和接触阴影。

原始 SVG 未覆盖；应用当前图标尚未替换。本版为 PNG 位图设计稿，不是可编辑矢量源文件。

## 文件

- `woodwind-icon-v2-1024.png`：标准尺寸主图，透明外边距。
- `woodwind-icon-v2-{512,256,128,64,32}.png`：缩小版本。
- `preview-light-dark.png`：深浅背景及小尺寸预览。
